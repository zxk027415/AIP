## 3. 统一六重验收策略（新 + 老一起）

不再按「填批 94」单独圈定；改为 **两集合求并**：

```
P4_TARGET = P4_NEW ∪ LEGACY_UNVERIFIED（44，不含 hdf5/mongodb）
VERIFIED  = six_layer_passed()  # 仍严格 L1∩…∩L6
```

每层做法（与 P3 一致）：

| 层 | Legacy 扩圈做法 |
|----|----------------|
| L1 | 写入 `LAYER1_META` + `EXPECTED_P4_*` / `EXPECTED_LEGACY_*` |
| L2 | `legacy_smoke_cases.py` → 并入烟测 |
| L3/L4 | `test_legacy_batch_coverage.py`（从 smoke 复用入参） |
| L5 | `TestEndToEndLegacyPipeline` 合成链路 |
| L6 | `test_e2e_legacy_realdata.py`（威海 + 光伏） |

门禁：`test_operator_verification.py::test_p4_and_legacy_batch_fully_covered`
