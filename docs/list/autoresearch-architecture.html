反馈回路

三条链路收成一条循环

  • 实验执行: Planner → Patch → Compare → MAPE
  • 候选晋级: Evidence → signature → novelty → verify → promote
  • 研究认知: 画像 → 归因 → 问题 → GLM假设 → 验证 → 知识

五层架构

  • 输入层: baseline / registry / windows / contract
  • 规划层: Planner / direction slots / GLM match
  • 执行层: patch route / compare / worker
  • 证据层: Evidence Record / novelty / question lifecycle
  • 沉淀层: Knowledge Claim / Reflection / promote

关键判断规则

  • 研究问题 ≠ 候选 patch（四级转换）
  • GLM Questioner ≠ GLM Proposal（两条路径）
  • 单窗口正收益 ≠ 可以 Promote（需复验）
  • candidate ≠ active knowledge（需多证据+场景匹配）
  • Planner 仍是并发组调度中心（防偏科）
