# 负荷预测项目融合到 AIP 工业AI算法平台 — 工作进度汇报

## 一、项目背景

将现有的电力负荷预测项目（基于 XGBoost + 贝叶斯超参优化）融合到 AIP 工业AI算法平台。核心策略是"薄包装、不侵入"：在现有代码之上添加一层轻量的 REST API 和 Agent Tool 适配层，同时把预测步骤注册为可视化编辑器中的 Function 节点，全程不修改现有核心模块。

### 技术栈

- **后端**：FastAPI + Python，负荷预测核心代码（XGBoost、贝叶斯优化、特征工程等）
- **前端**：React 18 + TypeScript + Ant Design 5 + ECharts + zustand
- **AI 对话**：DeepSeek v3.1 LLM + OpenAI Function Calling

## 二、第一阶段：负荷预测代码融合到 AIP 平台

### 2.1 REST API 端点创建

在 `AIP-service/backend/api/load_forecast.py` 中创建了 5 个 REST API 端点，内部通过 `import` 直接调用现有负荷预测核心代码：

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/load-forecast/train` | POST | 触发模型训练（异步，后台线程执行） |
| `/api/load-forecast/predict` | POST | 执行预测推理 |
| `/api/load-forecast/backtest` | POST | 回测评估（异步，后台线程执行） |
| `/api/load-forecast/scenarios` | GET | 获取 6 种预测场景配置 |
| `/api/load-forecast/status/{task_id}` | GET | 查询任务状态和实时日志 |

训练流程包含 4 个步骤：**数据获取 → 异常检测 → 特征工程 → 模型训练**，每个步骤的开始、完成、耗时都会记录到内存任务状态存储中。

### 2.2 路由注册

在 `main.py` 中注册负荷预测路由：
```python
from api.load_forecast import router as load_forecast_router
app.include_router(load_forecast_router)
```

### 2.3 Agent Tool 集成

在 `services/agent_tools.py` 中添加了 5 个 Agent Tool 定义，让大模型能通过 Function Calling 触发负荷预测操作：

- `trigger_load_forecast_train` — 触发训练
- `trigger_load_forecast_predict` — 触发预测
- `trigger_load_forecast_backtest` — 触发回测
- `get_forecast_scenarios` — 获取场景列表
- `get_forecast_status` — 查询任务状态

每个工具内部通过 `httpx.AsyncClient` 调用对应的 REST API 端点。

### 2.4 LLM 降级关键词匹配

在 `algorithm_agent.py` 的 `generate_response` 函数中添加了负荷预测关键词匹配规则引擎，当 LLM 不可用时自动降级：

- "训练"/"train" → `trigger_load_forecast_train`
- "预测"/"predict"/"forecast" → `trigger_load_forecast_predict`
- "回测"/"backtest" → `trigger_load_forecast_backtest`
- "场景"/"scenario" → `get_forecast_scenarios`

### 2.5 System Prompt 更新

在 Algorithm Agent 的系统提示词中添加了负荷预测领域知识，包括六种场景的适用范围、工具列表和标准对话流程。

### 2.6 场景知识库

在 `data/forecast_scenarios.json` 中添加了 DI/D/WI/W/MI/M 六种负荷预测场景的详细配置，包括业务描述、数据要求、精度目标和推荐配置。

### 2.7 AutoResearch Skill 包

在 `data/skills/load-forecast/` 目录下创建了三个文件：

- `program.md` — 实验手册（定义实验目标、规则、输出格式）
- `prepare.py` — 只读数据准备和评估函数（SMAPE 计算与 `utils.py` 一致）
- `train.py` — 可编辑训练脚本（XGBoost + 贝叶斯优化基线）

在 `packaged_skills.json` 中注册了"负荷预测 AutoResearch Skill"条目。

### 2.8 Function 节点注册

在 `functions.json` 中注册了 6 个负荷预测 Function 节点：

1. `load_forecast_data_fetch` — 负荷数据获取（category: data_source）
2. `load_forecast_anomaly_detection` — 异常检测与数据补全（category: data_preprocessing）
3. `load_forecast_feature_engineering` — 特征工程（category: feature_engineering）
4. `load_forecast_model_train` — 模型训练（category: model_training）
5. `load_forecast_model_predict` — 模型推理（category: ts_forecast）
6. `load_forecast_evaluate` — 预测评估（category: evaluation_metrics）

在 `ExecutionService._execute_function_node` 中实现了对应的执行逻辑。

### 2.9 向后兼容性

- 现有的 `python run.py --config configs/xxx.yaml` 命令仍能正常执行
- REST API 通过 `import` 调用现有函数，不复制代码
- 不修改 `db_data_fetch.py`、`data_process.py`、`features/engine.py`、`models_pkg/trainer.py`、`models_pkg/wrapper.py` 等核心模块

### 2.10 兼容性问题解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `utils` 模块名冲突 | `AIP-service/backend/utils/` 包与项目根的 `utils.py` 冲突 | `sys.modules` 缓存清理 |
| `bayesian-optimization` 版本不兼容 | v3.x 移除了 `UtilityFunction` | 降级到 1.4.3 |
| `mlflow` 缺失 | `LoadForecastWrapper` 继承 `mlflow.pyfunc.PythonModel` | 安装 mlflow |
| pandas 2.x `closed` 参数 | `pd.date_range(closed='left')` 在 2.x 中改名 | monkey-patch 兼容补丁 |
| `offline_load_data` 返回 None | 空 `parent_id`/`child_id` 导致数据过滤为空 | `or` 默认值兜底 |

## 三、第二阶段：多方式触发负荷预测

### 3.1 Curator Agent 意图识别

在 `services/curator_agent/master_agent.py` 中添加了 `load_forecast_action` 意图分类，关键词包括"触发"、"训练负荷"、"负荷回测"等。当识别到该意图时，直接调用 Agent Tool 执行操作，并返回跳转指令。

### 3.2 前端自动跳转机制

在 `AlgorithmAgentPage.tsx` 中添加了导航检测逻辑：当 Agent 响应中包含 `navigate-load-forecast-training` action 时，1.5 秒后自动跳转到训练可视化页面，并通过 URL 参数传递场景类型等预填参数。

### 3.3 工作流编辑器触发

在 `WorkflowEditorPage.tsx` 的 `handleExecute` 函数中添加了负荷预测节点检测：当工作流包含 `load_forecast_*` 节点时，点击"执行"按钮会直接跳转到训练可视化页面，而不是在工作流中逐步执行。

### 3.4 行业场景触发

- 在 `IndustryScenarioPage.tsx` 中，楼宇园区 → 负荷预测模板卡片上新增"触发训练"按钮
- 在 `AlgorithmSolutionLibraryPage.tsx` 中，已挂载的负荷预测工作流旁新增"触发训练"按钮

### 3.5 工作流模板创建

创建了 `workflow-load-forecast-pipeline.json` 工作流模板文件，包含 6 个负荷预测 Function 节点和连线，可在工作流编辑器中加载和挂载。

### 3.6 侧边栏入口隐藏

从 `MainLayout.tsx` 侧边栏中移除了"负荷预测训练"直接入口，改为通过上述触发方式跳转访问。

## 五、第四阶段：可视化逻辑改进优化

### 5.1 训练异步化

将 `/train` 和 `/backtest` 端点从同步改为异步：API 立即返回 `task_id`，训练/回测在后台线程执行。前端通过轮询 `/status/{task_id}` 实时跟踪进度，解决了前端请求超时问题。

### 5.2 后端日志实时推送

在 `_train_sync` 函数中添加 loguru sink，将训练过程中所有 `logger.info/error` 输出实时捕获到 `task_store` 的 `logs` 数组中。前端轮询时优先使用后端日志，实现了训练日志的实时展示。

### 5.3 参数表单简化

将 `parent_id`、`child_id`、`csv_path` 从必填字段改为高级选项（折叠隐藏），设置合理的默认值。用户只需选择预测场景即可一键训练。

### 5.4 参数注解

为预测步长、时间粒度、分段建模、预测起始时间四个参数添加了 tooltip 注解，鼠标悬停显示说明。

### 5.5 回测功能增强

- 快速回测默认从 7 天改为 2 天，加快测试速度
- 新增自定义日期范围回测（DateRangePicker + 回测按钮）
- 回测结果图表改进：折线图显示每日均值/最大值/最小值三条曲线

### 5.6 节点删除功能

在 `EnhancedCanvas.tsx` 中添加了 Delete/Backspace 键删除选中节点的功能，解决了工作流编辑器中无法删除节点的问题。

### 5.7 URL 参数预填

`LoadForecastTrainingPage` 支持通过 URL 参数（`task_type`、`parent_id`、`child_id`、`csv_path`）自动预填表单，实现从 Agent 对话或工作流编辑器跳转时的参数传递。

## 七、使用说明

### 7.1 启动服务

**后端**（在 `AIP-service/backend` 目录下）：
```bash
conda activate cp_web
python -m uvicorn main:app --reload --port 8000
```

**前端**（在 `AIP-service/frontend` 目录下）：
```bash
npm run dev
```

### 7.2 触发负荷预测训练的 4 种方式

#### 方式一：AI 对话触发（推荐）

1. 打开 http://localhost:5173/algorithm-agent
2. 选择 **Curator Agent（算法策划）**
3. 输入"帮我触发负荷预测训练，场景类型D"
4. Agent 自动识别意图，1.5 秒后跳转到训练可视化页面
5. 场景自动选中，点击"开始训练"

#### 方式二：行业场景触发

1. 打开 http://localhost:5173/industry
2. 点击"楼宇园区"场景卡片
3. 找到"负荷预测"模板，点击"触发训练"按钮
4. 自动跳转到训练可视化页面

#### 方式三：算法方案库挂载触发

1. 打开 http://localhost:5173/algorithm-solutions
2. 左侧树展开 楼宇园区 → 负荷与需求侧管理 → 负荷预测
3. 右侧业务场景点击"挂载模板"
4. 搜索"负荷"，选择"负荷预测完整流水线"，点击"挂载"
5. 挂载后点击"触发训练"按钮

#### 方式四：工作流编辑器触发

1. 打开 http://localhost:5173/workflow/editor
2. 点击"打开" → 选择"负荷预测完整流水线"
3. 点击"执行"按钮
4. 系统检测到负荷预测节点，自动跳转到训练可视化页面

### 7.3 训练可视化页面操作

1. **选择场景**：点击 6 种场景卡片之一（DI/D/WI/W/MI/M）
2. **配置参数**：预测步长、时间粒度等保持默认即可；高级选项可展开配置数据源
3. **开始训练**：点击"开始训练"按钮
4. **查看进度**：进度条实时显示 4 个步骤状态，日志面板显示后端详细日志
5. **查看结果**：训练完成后展示 Model ID、总耗时、步骤耗时图表

### 7.4 回测验证

训练完成后，结果仪表盘下方提供两种回测方式：

- **快速回测**：一键按钮，默认回测最近 2 天
- **自定义回测**：选择日期范围，点击"自定义回测"按钮

回测结果展示：
- 成功/跳过/失败天数统计
- 每日预测值折线图（日均负荷、日最大负荷、日最小负荷）
- 每日回测预测点数量柱状图

### 7.5 训练历史

右侧"训练历史"面板记录当前会话的所有训练记录，点击某条记录可回填参数重新训练。

### 7.6 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 预测场景 | DI(日内)/D(日前)/WI(周内)/W(周前)/MI(月内)/M(月前) | 必选 |
| 预测步长 | 预测未来多少天。D 通常设 1，W 设 7，M 设 30 | 1 |
| 时间粒度 | 数据采样间隔，需与实际数据匹配 | 15分钟 |
| 分段建模 | 工作日/节假日分别训练独立模型 | 关闭 |
| 预测起始时间 | 每天从几点开始预测 | 00:15 |
| CSV 数据文件路径 | 高级选项，留空使用默认数据文件 | 自动 |
| 父节点 ID / 子节点 ID | 高级选项，留空使用默认值 | park_01 / yARGkDuq |

### 7.7 API 文档

后端启动后，访问 http://localhost:8000/docs 可查看完整的 Swagger API 文档，包括所有负荷预测端点的请求/响应格式。
