# 第七代前端重构 image2 高保真提示词

## 使用说明

本文件用于在中保真方向确认后，生成第七代前端重构的高保真视觉稿。  
当前已确认的中保真主方向：

```text
A 平衡型控制台
+ 吸收 B 强表格型工作台的高密度版本列表能力
```

高保真阶段的任务不是重新发明页面结构，而是把已确认的结构打磨成可工程化实现的视觉稿。

## 全局高保真提示词

```text
请为一个工业 AI 算法平台设计高保真后台界面。

这是业务工作台，不是营销官网。
目标用户是算法工程师、工业数据工程师、算法运维人员。

产品目标：
让用户从行业场景进入算法开发，再进入工作流编排、自动化回测、算法运营和部署。

视觉方向：
- 工业算法控制台
- 高信息密度
- 清楚的视觉层级
- 稳定的左侧导航
- 克制、专业、工程化

严格约束：
- 不要做 hero
- 不要做营销式大横幅
- 不要做装饰性插画
- 不要大面积紫色或蓝紫渐变
- 不要 oversized 卡片
- 不要多层嵌套卡片
- 不要用过圆的圆角，控制在 8px 以内
- 不要为了好看牺牲表格密度和操作效率
- 页面主体优先使用 Ant Design 后台语义的表格、筛选栏、状态标签、按钮、Tabs、Drawer、Modal

页面主线：
行业场景 -> 推荐方案/模板 -> 工作流开发 -> AutoResearch 回测优化 -> 精度运营 -> 部署上线

必须保留：
- 左侧导航中的“行业服务”和“算法开发”分组
- “算法管理”作为算法开发默认首页
- 工作流版本状态：开发中、候选、复验通过、生产/影子
- 新建工作流向导
- 算法管理首页中的场景分组 + 紧凑版本表格

输出要求：
- 提供桌面端高保真主画面
- 提供移动端或窄屏适配版本
- 字体、颜色、间距、状态标签要一致
- 所有按钮内文字必须完整可读
- 表格、标签、筛选条、分组标题要可工程实现
```

## 页面 1：算法管理首页

```text
请生成工业 AI 算法平台“算法管理”页面的高保真后台界面。

路由：
/algorithm-dev/management

页面目标：
按行业场景管理算法工作流版本，连接工作流编排、AutoResearch、算法运营和算法部署。

页面结构：
1. 左侧固定导航
2. 顶部页面标题与简短说明
3. 筛选区：
   - 场景筛选
   - 搜索框
   - 状态筛选
   - 视图切换
   - 新建算法工作流按钮
4. 统计区：
   - 场景数
   - 工作流数
   - 开发版本数
   - 运营中版本数
   - 待部署版本数
5. 主体区：
   - 按行业场景分组
   - 每个场景内是高密度紧凑版本表格
   - 表格列包含：算法名称、版本、最近回测、复验状态、运营状态、更新时间、操作

操作按钮：
- 编辑
- 回测
- 运营
- 部署

状态标签：
- 开发中
- 候选
- 复验通过
- 生产
- 影子
- 退役（可弱化）

设计要求：
- 场景分组清晰但不过度卡片化
- 表格视觉要紧凑但不拥挤
- 筛选区和统计区清晰分层
- 更像工程控制台，而不是 BI 大屏
- 所有操作按钮要适合频繁点击
```

## 页面 2：新建算法工作流向导

```text
请生成工业 AI 算法平台“新建算法工作流”向导的高保真后台界面。

页面目标：
让用户先选择行业场景，再选择推荐模板，再决定基于模板创建还是空白创建。

流程：
1. 选择行业场景
2. 查看推荐模板
3. 选择创建方式
4. 进入工作流编辑器

界面形式：
- 推荐用 Modal / Drawer / 向导页
- 明确的步骤条
- 清楚的场景卡片
- 清楚的模板卡片

模板卡片字段：
- 模板名称
- 适用场景
- 模板类型（训练 / 预测 / 回测 / 闭环）
- 简短说明
- 推荐原因（可选）

创建方式：
- 基于模板创建（主入口）
- 空白创建（次入口）

设计要求：
- 不要像电商下单流程
- 不要过度游戏化
- 保持工程后台气质
- 信息明确、一步一步推进
- 强调“推荐模板”比“空白创建”更高优先级
```

## 页面 3：算法管理到 AutoResearch 的衔接

```text
请生成工业 AI 算法平台中“算法管理 -> 自动化回测”衔接页的高保真后台界面。

页面目标：
让用户从某个工作流版本发起 AutoResearch，并看到版本状态流转。

页面应展示：
- 当前工作流名称
- 当前版本
- baseline 信息
- AutoResearch 入口
- 候选版本列表
- 复验状态
- Promote 状态
- 返回算法管理按钮
- 进入算法运营按钮

设计重点：
- 强调版本流转关系
- 不要做成论文实验面板
- 更像“算法优化工作台”
- 候选、复验、Promote 状态要一眼能区分
```

## 风格守则

### 推荐

- 浅色底 + 深色文字的专业后台风格。
- 中性色为主，状态色作为强调。
- 细边框、紧凑间距、明确分隔。
- 主操作按钮克制但清晰。
- Tabs、Segmented、Table、Tag、Dropdown、Modal、Drawer 优先。

### 避免

- 大面积空白导致信息密度不足。
- 炫技渐变和装饰性噪点背景。
- 圆角过大。
- 彩色过多，导致状态色失真。
- 夸张阴影。
- 表格列过松。

## 高保真阶段的交付要求

每个页面至少应交付：

- 桌面端主视图。
- 移动端/窄屏视图。
- 关键状态视图（如空状态、列表有数据状态）。
