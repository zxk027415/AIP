# 迭代标注系统 - 工作流界面集成方案

## 📋 需求

将迭代标注的完整流程集成到工作流管理界面，用户可以：
- ✅ 在工作流列表中看到"迭代标注工作流"
- ✅ 点击创建/打开迭代标注工作流
- ✅ 在统一的界面完成：数据上传、训练、预测、审核、回流的全流程
- ✅ 无需使用命令行API调用

---

## 🎯 设计方案

### 方案A：独立的迭代标注管理页面（推荐）⭐

在工作流导航中新增"迭代标注"入口，创建专门的迭代标注管理界面。

#### 页面结构

```
工作流导航
├── 工作流列表
├── 工作流编辑器
├── Baseline比对
└── 迭代标注 ⭐ (新增)
    ├── 闭环列表
    ├── 创建闭环向导
    ├── 训练配置
    ├── 预测配置
    ├── 审核会话
    └── 迭代历史
```

#### 优点
- ✅ 专门针对迭代标注场景优化
- ✅ 完整的向导式流程，易用性强
- ✅ 不影响现有工作流功能
- ✅ 开发量适中

#### 缺点
- ⚠️ 需要新增独立页面

---

### 方案B：集成到现有工作流编辑器

在现有工作流编辑器中新增"迭代标注"模式。

#### 优点
- ✅ 复用现有编辑器框架
- ✅ 用户无需切换页面

#### 缺点
- ❌ 工作流编辑器已经很复杂
- ❌ 迭代标注流程与普通工作流差异大
- ❌ 难以提供良好的用户体验

---

## 🎯 用户体验目标

完成后，用户可以：

1. **进入迭代标注页面**
   - 左侧导航 → 迭代标注

2. **创建新闭环**
   - 点击"创建新闭环"
   - 填写表单、上传数据、配置参数
   - 点击创建，自动开始训练

3. **查看进度**
   - 在闭环列表看到所有闭环
   - 点击详情查看当前状态

4. **继续流程**
   - 训练完成 → 上传预测数据 → 开始预测
   - 预测完成 → 进入审核页面 → 人工审核
   - 审核完成 → 回流数据 → 开始下一轮

5. **全程无需命令行**
   - 所有操作都在界面完成
   - 直观、易用
