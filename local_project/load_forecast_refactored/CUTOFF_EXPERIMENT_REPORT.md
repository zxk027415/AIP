# 数据截取方式预测实验报告

## 1. 实验背景

在前期数据穿越检测工作中，我们通过 `verify_no_leakage.py` 验证了 `run_weihai_backtest.py` 中 mask 方式（将测试集 load 置为 NaN）的有效性，8 项检测全部通过。

本次实验根据领导要求，采用**"数据先截取"**的方式进行预测验证：先将数据截取到预测日之前，再做特征工程和模型训练，从源头杜绝数据穿越的可能性。

## 2. 实验设计

### 2.1 预测目标

- 预测日：2026-04-01（星期三，工作日）
- 预测粒度：15 分钟，共 96 个点
- 训练窗口：30 天（2026-03-01 ~ 2026-03-31）

### 2.2 两种防穿越方式对比

| | mask 方式 | 截取方式（本次实验） |
|---|---|---|
| 实现文件 | `run_weihai_backtest.py` | `predict_first_day.py` |
| 数据处理 | train + test 合并，test 的 load 置为 NaN | 数据截取到 3/31 23:45，追加 96 行空行（load=NaN） |
| 防穿越原理 | 未来 load 被 NaN 遮住，shift/diff 取到 NaN | 未来数据根本不存在于输入中 |
| 安全性 | 依赖"记得 mask"这个操作 | 从源头不可能穿越 |

### 2.3 截取方式的具体流程

```
Step 1: 加载威海数据（2025-07-02 ~ 2026-04-07，26867 行）
Step 2: 截取到 < 2026-04-01（保留到 2026-03-31 23:45:00，26208 行）
Step 3: 追加预测日 96 行空行（load=NaN），合计 26304 行
Step 4: 在合并数据上做特征工程（与 run_weihai_backtest.py 完全一致）
Step 5: 取训练窗口 30 天数据训练模型
Step 6: 预测 2026-04-01 的 96 个点
Step 7: 与真实值对比评估
```

### 2.4 模型配置

- 多模型集成：XGBoost + LightGBM + CatBoost + Ridge
- 交叉验证：TimeSeriesSplit（5 折）
- 超参优化：贝叶斯优化（3 初始点 + 12 轮迭代）
- 集成权重：基于 OOF RMSE 的逆误差自适应加权

- Ensemble 整体比值 2.4x，在合理范围内

## 7. 截取方式 vs mask 方式对比

| 方式 | SMAPE | MAE (kW) | RMSE (kW) |
|------|-------|----------|-----------|
| mask 方式（run_weihai_backtest） | 2.78% | 683.8 | 896.8 |
| 截取方式（predict_first_day） | 2.76% | 685.8 | 885.8 |
| **差异** | **-0.02%** | **+2.0** | **-11.0** |

两种方式精度几乎一致（SMAPE 差 0.02%），说明：

1. **mask 修复是有效的** — 如果 mask 方式仍有穿越，其精度应"虚高"，明显优于截取方式
2. **截取方式从源头杜绝了穿越** — 未来数据根本不存在于输入中
3. **当前精度是模型的真实能力** — 不存在穿越带来的虚假精度

## 8. 误差分析

### 8.1 整体误差特征

- 系统性高估：71/96 个点（74%）为高估，Bias = +491 kW
- 误差集中在上午：08:00-09:00 时段误差最大，真实负荷出现明显低谷（~22,000 kW），模型预测仍在 25,000-26,000 kW

### 8.2 上午高估原因分析

4/1 上午负荷出现了低于历史同期的"谷"，可能原因：
- 季节转换：3 月→4 月，气温升高导致供暖负荷下降，模型基于 3 月数据训练，未充分捕捉这一变化
- 光伏出力增加：春季日照增强，分布式光伏出力增加，净负荷下降
- 当天特殊事件：部分设备检修或调度调整

### 8.3 夜间和晚间表现良好

夜间（00-06）和晚间（18-24）SMAPE 均在 1.3% 以内，说明模型对基荷和晚高峰的预测能力较强。

## 9. 结论

1. **数据穿越问题已解决**：截取方式与 mask 方式精度一致，验证了两种防穿越方案的有效性
2. **截取方式更安全**：从源头杜绝穿越可能，不依赖人工 mask 操作，建议作为标准做法
3. **训练拟合良好**：Ensemble 训练 R²=0.9776，SMAPE=1.16%，无严重过拟合（除 LightGBM 轻微）
4. **模型真实精度**：测试集 SMAPE 2.76%，R²=0.9199，主要薄弱环节在上午时段的季节性变化捕捉
