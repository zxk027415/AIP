## 4. 轨迹点标记规范（必须遵守）

| 形状 | 线型 | 颜色 | 语义 |
|------|------|------|------|
| 圆圈 dot | 实线 | 蓝 `#1e63d6` | 实际运行精度（基线/稳定） |
| 圆圈 dot | 实线 | 红 `#d73c36` | 事故日劣化精度（已发生） |
| 圆圈 dot | 实线(半透明) | 红 `#d73c36` opacity 0.75 | **未修复曲线**：不修复时后续日期精度 |
| 菱形 diamond | **虚线** dashed | 绿 `#11874d` | 事故日恢复精度（**待上线，未实际应用**） |
| 菱形 diamond | **实线** solid | 绿 `#11874d` | 次日恢复模型**已上线在用** |

**事故日竖直对齐**：同一日期 x 坐标上同时出现：
- 下方红色圆圈（劣化）
- 上方绿色虚线菱形（恢复待上线）

**修复 vs 未修复双曲线对比**（事故日之后）：
- 绿色实线菱形：修复后新模型上线精度（高位）
- 红色圆圈（半透明）+ 红色虚线连线：未修复时旧模型持续劣化精度（低位）
- SVG 中红色虚线 `stroke-dasharray="8 5" opacity="0.7"` 连接各未修复点
- 图例三栏：事故前稳定 / 恢复(◇实线菱形) / 未修复(○红色圆圈)

**未修复精度模拟逻辑**：
- 事故日 nofix_acc = degraded_acc（与劣化精度相同）
- 后续每天 nofix_acc = degraded_acc + days_after × 1.2pp（自然缓慢回升，因 lag 窗口逐步滑出缺失区间）

**禁止**：用圆圈表示恢复后版本；用实线菱形表示未上线状态。
