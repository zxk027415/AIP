# 领域知识库（CoE 专家经验）

## 1. 特征工程知识

### Gap 模式特征工程（次日预测）

```
时间线:
  D+1 = 预测目标日（需要预测的日期）
  D   = 今天（当天数据不可用 — "gap"）
  D-1 = 昨天（Gap一天模式下可用的最近数据）

Gap一天基线: 特征从 D-1 起取
  lag_1d → 实际取的是 D-1 的值
  lag_2d → D-2
  rolling → 基于 shift(1天) 的滑动统计
```

### 特征分组

| 组名 | 包含特征 | 典型重要性 | 说明 |
|------|----------|-----------|------|
| lag | lag_1d, lag_2d, ..., lag_28d | 40-50% | 历史同期真值，最关键 |
| rolling | roll_mean_4/16/96/672, roll_std_* | 25-35% | 滑动统计，捕捉趋势 |
| calendar | period, dayofweek, month, is_weekend, sin/cos编码 | 10-15% | 周期模式 |
| weather | temperature, wind_speed | 5-10% | 气象驱动（本资产不敏感） |

### 关键认知

- **lag_1d 是量级锚点**：gap 一天模式下，lag_1d 直接取 D-1 的值，是模型预测的主要参考基准
- **rolling 依赖 lag**：rolling 统计基于 shifted load，如果 lag 源数据 NaN，rolling 也被污染
- **calendar 和 weather 独立**：不依赖历史负荷数据，数据缺失不影响

## 2. 精度基准

| 场景 | Accuracy 范围 | 说明 |
|------|--------------|------|
| 健康基线 | 96-98% | 数据完整 + 模型正常 |
| D-1 全天缺失（未修复） | 70-75% | lag_1d 全 NaN |
| D-1 缺失 + pred_fill 恢复 | 90-93% | 代理值保住锚点 |
| D-1 缺失 + extra_gap 恢复 | 88-91% | 退到 D-2 但丢信息 |
| 劣化阈值 | < 90% | 低于此触发运营 |
| 恢复目标 | ≥ 85% | 恢复至此算成功 |

## 3. 故障模式图谱

### 故障A：近邻日整天缺失

```
触发: D-1 全天 96 点 load = NaN
级联: lag_1d 全 NaN → rolling 短窗被污染
影响: 精度跌 20-28pp
特征: 突发（前一天正常）
```

**候选策略:**

| 策略 | 做法 | 优势 | 劣势 | 典型精度 |
|------|------|------|------|----------|
| pred_fill_dm1 | 用 gap 模型预测 D-1，当代理真值回填 | 保住 lag_1d 锚点 | 代理误差 | 91-93% |
| extra_gap | 跳过 D-1，从 D-2 起算 | 安全不引入假值 | 丢近期信息 | 88-91% |

**选择逻辑:**
- pred_fill 精度通常高 2-3pp → 默认首选
- 但如果 D-1 是突变日（节假日/极端天气），预测值不可靠 → 选 extra_gap
- 基线对 D-1 预测精度 97%+ 时，回填的代理误差可接受

### 故障B：多天连续缺失（D-1 + D-2 同时丢失）

```
触发: 连续 2+ 天数据缺失
级联: lag_1d, lag_2d 均 NaN，rolling 全窗被污染
影响: 精度跌 30-40pp
```

### 故障C：散落缺失

```
触发: 某天部分点（非整天）缺失
级联: 对应 lag 部分 NaN，rolling 受影响但程度较轻
影响: 精度跌 5-15pp
```

## 4. 决策原则

1. **精度优先**：实测精度是最终判据，理论分析只做参考
2. **保守原则**：不确定时选风险更低的策略
3. **信息量守恒**：尽量保留近期信息（lag_1d 是量级锚点）
4. **误差隔离**：引入代理值时要评估误差传播
5. **可逆性**：优先选可回退的策略

## 5. RCA 置信度评估规则

| 条件 | 置信度范围 |
|------|-----------|
| 精度跌幅 > 15pp + 证据链完整 + 因果一致 | ≥ 0.85 |
| 精度跌幅 5-15pp + 部分证据吻合 | 0.6-0.85 |
| 证据矛盾或多因素交叉 | < 0.6 → undetermined |
| 无法确定根因 | 0.0 → undetermined = true |

## 6. 预防建议

- 建立负荷采集多通道冗余
- 设置入库超时告警（15分钟无数据则预警）
- 预置 gap 降级预案（自动切换到 extra_gap）
